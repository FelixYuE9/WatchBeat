# 单导联 ECG 能力与竞品功能调研

日期：2026 年 10 月 9 日。范围为 WatchBeat 当前的 Apple Watch 类 I 导联、单次约 30 秒 ECG，以及可借鉴的消费端和专业分析软件。

建议先补齐可核对的间期统计、图表和数据质量，再推进新的心律分类。本轮已接入平均 RR、SDRR、RR 变异系数、相邻差值均方根、pRR50、RR 直方图和相邻间期散点图。下一轮最值得投入的是客观信号质量与早搏召回率；PAC/PVC 分型、房颤和传导异常需要独立验证，不能直接用竞品的标签扩充当前算法。

## 单导联能回答哪些问题

“心悸、胸闷、头晕”是主观症状，ECG 能记录症状发生时的心电活动，不能仅凭一段波形确定症状原因。产品应分开记录用户感受、算法候选和医生结论。Apple Watch 官方 ECG 每次记录 30 秒，输出类似 I 导联的波形；它适合提供心率、心律信息，不能识别心脏病发作。[Apple 官方说明](https://support.apple.com/en-us/120278)

| 信息或问题 | 单导联的能力与条件 | WatchBeat 建议 |
| --- | --- | --- |
| 心率偏快或偏慢 | R 峰可靠时可测心率；运动、休息状态和年龄影响解释。数值不能单独判断病因 | 先提供本次中位心率、范围和可复核间期，保留上下文 |
| 房颤 AF | 可作为医生判读的 ECG 证据；自动提示需复核，噪声和频发早搏会干扰 | 后续独立研究，不用 CV 或 RR 不规则性直接诊断 |
| 房早 PAC 和室早 PVC | 高质量单导联可出现识别线索；区分两者需要形态、P 波和时序证据 | 当前继续用“疑似早搏候选”；下一步补形态证据和质量门控 |
| 规则的快速节律和 SVT | 可记录发作时节律，但具体机制的区分需要专业判读和进一步检查 | 先提供事件片段及发生时心率；暂不自动命名具体 SVT |
| 宽 QRS 和室性快速节律 | 单导联可能捕获异常；宽 QRS 不是室早或室速的充分条件 | 在可靠 QRS 边界测量前不增加自动诊断 |
| 长间歇和停搏样表现 | 可观察长 RR；漏检 R 峰和接触不良也会造成长间隔 | 保留“长 RR”描述并支持定位原波形，不标成确诊停搏 |
| 房室传导异常 | P 波清晰时专家可能判断部分异常；P 波不可见不能解释为不存在。[人工复核范围](https://store.kardia.com/clinician-reviews) | 手动测量优先，自动 PR 或 AV block 暂缓 |
| 心梗、心肌缺血、结构性心脏病 | 当前腕表单导联不能用于可靠诊断或排除 | 不加入此类自动结论 |

房颤的确定诊断需要医生复核 ECG。2024 ESC 指南区分设备筛查与 ECG 确诊，而非让设备提示直接替代诊断。[2024 ESC 房颤指南](https://academic.oup.com/eurheartj/article/45/36/3314/7738779)

一项以电生理检查为参照的研究在 49 位患者中记录了 843 次节律观察，盲法阅读者对单导联 Kardia 波形的 SVT、VT 和 PVC 判读准确率分别为 89%、91%、91%。这些是特定临床环境下的人工判读结果，不能推导为 WatchBeat 自动模型或普通用户在家记录的准确率。[Turnbull 等，2024](https://pubmed.ncbi.nlm.nih.gov/38971645/)

对于房颤，包含既有心血管疾病患者的研究发现，人工复核与消费设备自动分类表现不同；频发早搏、其他房性心律和植入设备也是容易被简单验证集忽略的干扰。[Europace 单导联验证研究，2023](https://esc365.escardio.org/journal/72241)

## 竞品提供什么

以下比较的是官方公开功能，不能把不同设备、记录长度、付费层级或医疗用途的结果直接横向排名。专业 Holter 软件的连续记录统计尤其不能移植成 30 秒腕表记录的全天负荷。

| 产品 | 数据和定位 | 公开统计与功能 | 值得借鉴的部分 |
| --- | --- | --- | --- |
| Apple Watch ECG | 按需 30 秒类 I 导联记录 | 心率、窦律或房颤分类、无法分类或记录质量提示、症状记录、PDF 分享 | 清晰的无法判断状态和带原波形的分享流程。[官方说明](https://support.apple.com/en-us/120278) |
| AliveCor Kardia | 消费端按需 ECG；有单导联与 6 导联设备 | Advanced Determinations 公开列出心动过缓、心动过速、PVC、SVE 和宽 QRS 等；部分能力需订阅 | 候选事件清单、人工复核路径、判读标签说明；不直接照搬医学结论。[功能目录](https://alivecor.zendesk.com/hc/en-us/sections/360003701573-Kardia-Advanced-Determinations)、[PVC 和 PAC 支持说明](https://alivecor.zendesk.com/hc/en-us/articles/360051956534-Can-the-KardiaMobile-or-the-KardiaMobile-6L-detect-PVCs-or-PACs) |
| Kubios HRV Scientific | ECG、PPG 或 RR 输入的专业 HRV 分析 | Mean RR、SDNN、RMSSD、pNN50、频域和非线性指标；噪声检测、搏动校正、时间窗分析、CSV/PDF 导出 | 显示原始与处理后的间期、处理比例、分析窗口和图表；先做好质量再解释指标。[产品说明](https://www.kubios.com/hrv-scientific/) |
| Welltory | Apple Watch、手机 PPG 或心率传感器的健康趋势产品 | SDNN、RMSSD、pNN50、CV、AMo50、直方图、趋势及压力/能量评分；频域需要更长记录模式 | 指标释义、历史趋势、直方图；不复制缺乏本项目验证的综合评分。[指标说明](https://help.welltory.com/en/articles/3878830-about-your-heart-rate-variability-metrics) |
| Bittium Cardiac Navigator | 专业临床 Holter 分析 | 事件条带、形态模板、HRV、噪声检测、P 波/AV block、QT/ST 分析和可定制报告 | 波形与事件关联、形态模板、人工编辑和报告结构；其高级分析不能视为腕表单导联已经具备的能力。[官方产品资料](https://www.bittium.com/wp-content/uploads/2024/10/Bittium_Cardiac_Navigator_2024_02_web.pdf) |
| PhysioNet Cardiovascular Signal Toolbox | 开源研究工具，MATLAB 波形或 RR 输入 | QRS、信号质量 SQI、异常/噪声预处理和 HRV 参数 | 用作透明的参考实现和验证设计来源；集成代码前另核许可证。[官方工具说明](https://physionet.org/content/pcst/1.0.0/) |

Kardia 的公开支持说明确实涵盖 PAC/PVC；“宽 QRS”说明则保留医生评估的必要性。它证明单导联可扩展的方向，不证明只用 RR 时序即可得到这些结论。[宽 QRS 说明](https://alivecor.zendesk.com/hc/en-us/articles/1500001726001-What-is-Sinus-Rhythm-with-Wide-QRS)

## 心率变异系数与其他指标怎么选

RR 是相邻检测 R 峰的间隔；NN 则要求相邻心搏已被确认属于正常窦性心搏。WatchBeat 当前的 `normal` 只表示“相对局部 RR 基线没有提前”，并非已确认正常窦律。因此本轮选择描述性 RR 统计，避免用 SDNN 或临床 HRV 名称掩盖输入条件。

“心率变异系数”需要注明公式。本轮采用 **CV_RR = 100 × SDRR / 平均 RR**。直接对逐搏心率计算标准差/均值是另一种指标，不能混称或混用参考值。CV 为无单位百分比，仍会受记录长度、早搏、噪声和检测误差影响。

| 指标 | 定义与单位 | 30 秒记录中的使用判断 |
| --- | --- | --- |
| 平均 RR | 纳入间期的算术平均，ms | 本轮加入；与已有中位 RR 并列，保留各自含义 |
| SDRR | RR 的样本标准差，ms；分母 n−1 | 本轮加入；不称 SDNN，不给健康范围 |
| CV_RR | 100 × SDRR / 平均 RR，% | 本轮加入；不同软件的标准差口径和预处理可能不同 |
| RMSSD_RR | 原序列相邻纳入 RR 的差值平方均值再开方，ms | 本轮加入描述性版本；早搏与误检会抬高数值 |
| pRR50 | 原序列相邻纳入 RR 对中，绝对差值 >50 ms 的比例，% | 本轮加入；分母为实际纳入的相邻对数，不能叫 pNN50 |
| SDNN、RMSSD、pNN50 | 使用经过质量处理、符合 NN 条件的序列 | 留待窦性心搏和质量验证，30 秒结果不与标准时长直接比较 |
| Poincaré、SD1、SD2 | 将相邻间期画成散点，进一步量化点云 | 本轮加入原始 RR 散点图；SD1/SD2 解释暂缓 |
| LF、HF、LF/HF、VLF | 频域功率及比值 | 暂缓；30 秒无法支撑常规低频谱解释，LF/HF 不直接当压力评分 |
| SDANN、SDNN index | 长记录中按 5 分钟窗口汇总 | 当前数据不匹配；不能拼接不同日期的 30 秒记录计算 |
| 压力、能量、恢复评分 | 多指标或个人基线上的产品解释 | 暂缓，缺少对应设备、记录协议和人群验证 |

经典 HRV 标准采用标准化短时记录口径，通常为 5 分钟；有些超短时指标可在特定协议下研究，但“能算出数值”并不等于已经验证为 5 分钟指标的替代品。[ESC/NASPE HRV 标准](https://pubmed.ncbi.nlm.nih.gov/8598068/)

Kubios 的用户指南展示了少量伪迹就能改变 SDNN 和 RMSSD，并要求处理伪迹、保留处理比例。WatchBeat 本轮的 300–2000 ms 范围筛选只排除不符合研究范围的间期，**不是伪迹校正，也不是信号质量评分**。[Kubios 用户指南，第 12 页](https://www.kubios.com/downloads/HRV-Scientific-Users-Guide.pdf)

示例：RR = 800、1000、1200 ms，平均 RR = 1000 ms，样本 SDRR = 200 ms，CV_RR = 20%，RMSSD_RR = 200 ms，pRR50 = 100%。这些数值只描述该序列。若中间有被排除的间期，不应把两侧间期当成原本相邻来计算差值。

## 功能优先级

以下排序是针对当前代码和公开验证结果的工程判断，不是医学指南推荐级别。

| 顺序 | 功能 | 用户价值 | 工作量与进入条件 | 决策 |
| --- | --- | --- | --- | --- |
| P0 | RR 统计、分布与相邻散点图 | 让已有 R 峰信息可读、可核对 | 较低；公式、单位、计数、断点和导出兼容必须清楚 | 本轮已接入源码 |
| P0 | 客观局部信号质量 | 减少把运动或接触伪迹当异常 | 中高；带专家质量标签的数据、Apple Watch 域验证、阈值冻结 | 下一轮优先 |
| P0 | 提升早搏召回率与误报控制 | 比增加医学标签更能改善核心功能 | 高；按患者隔离的开发/验证/测试集，噪声和节律分层评测 | 与质量建设一起推进 |
| P1 | 候选连续序列和二/三联样模式定位 | 快速复核集中出现的候选 | 中；质量门控、序列边界、重复模式及漏检验证 | 用描述性命名，不直接称成对室早或 NSVT |
| P1 | 症状与事件的记录级关联 | 找到用户不舒服时录下的片段 | 中；区分有症状无候选、有候选无症状及未分析 | 扩展已有标签与概览，避免因果推断 |
| P1 | 结构化分享摘要 | 帮助医生快速看原波形与事件 | 中；记录长度、纳入/排除数、症状、候选时间、算法版本 | 值得添加，原始波形应可追溯 |
| P2 | PAC/PVC 形态证据 | 提供更具体的候选信息 | 高；可靠 P/QRS 特征、专家标注、外部设备验证 | 达标前保持 uncertain |
| P2 | 独立房颤候选模型 | 扩大心律研究能力 | 高；AF/早搏/房扑/噪声鉴别和拒判评估 | 不把 Apple 分类作为独立模型输入 |
| P3 | 长时 RR 导入及经过验证的 HRV | 支撑可比较的标准时长分析 | 高；新数据协议、质量与 NN 处理验证 | 当前单次腕表 ECG 之外的后续方向 |

仓库的 MIT-BIH 开发集基线中，早搏候选灵敏度为 44.9%、阳性预测值为 66.7%。这是公开数据开发集结果，不能表示 Apple Watch 真机性能；也意味着“本次没有候选”不能当成“没有早搏”，候选影响提示无法覆盖未检出的早搏。[仓库验证记录](VALIDATION.md)

## 本轮实现口径

- 新增可选导出字段 `rrVariability`，版本 `watchbeat.rr-variability.v1`；旧 schema v1 报告仍可解码，拒判时不生成统计。
- 统计纳入 300–2000 ms 间期，至少两个纳入间期才生成；相邻差值指标没有有效相邻对时为空。
- 统计和图表使用同一份间期范围筛选；排除项保持断点，不插值、不跨断点配对。
- 显示记录时长、纳入/检测间期数、排除数、相邻对数、连接疑似候选的间期数。候选保留在 RR 统计中，并提示它们可能抬高数值。
- 详情页增加中英双语数值、50 ms 分箱直方图和 Poincaré 散点图；不给正常范围、好坏颜色或疾病解释。
- 所有计算在本机复用已检测 R 峰，不改变 R 峰位置、早搏分类、原始样本或筛查缓存内容。当前统计仅出现在详情和用户主动触发的分析 JSON 导出中。

JSON 字段、公式和计数的完整约定见 [输出契约](CONTRACTS.md)。构建与真机验收项见 [Mac 验证清单](../NEEDS_MACOS_VALIDATION.md)。
